## 5. Risks and fallbacks
| Risk | Sign | Fallback (decide with Bhargavi) |
|---|---|---|
| Next.js + Python in one Vercel project misbehaves (routing/build) | `/api/health` 404 on Vercel but works locally | Deploy FastAPI as a second Vercel project (`memo-to-cash-api`), set `NEXT_PUBLIC_API_BASE`, enable CORS for the web origin only |
| Python version on Vercel isn't 3.12 | build log shows other version | Pin via Vercel's supported mechanism (e.g. `.python-version` / project setting); keep code 3.11-compatible |
| Llama key/model not available (waitlist, wrong id, region) | `llama_smoke` 401/403/404 | Stop and ask. Options: correct model id from `/compat/v1/models`; or same Llama model via another OpenAI-compatible host (needs Bhargavi's OK and a new key) |
| Neon connection errors on serverless | intermittent `db:false` | Confirm pooled URL + `sslmode=require` + `NullPool`; migrations only via unpooled URL |
| Cold start slow | first request > 3 s | Acceptable in P0; note it. Health must still return within Vercel's limit |
