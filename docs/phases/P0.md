## 5. Risks and fallbacks
| Risk | Sign | Fallback (decide with Bhargavi) |
|---|---|---|
| Web → api private network not reachable | `/api/health` 502 on web, but the api's own URL works | Proxy accepts a full base URL too: set `API_INTERNAL_BASE=https://memo-to-cash-api.onrender.com` (overrides `API_INTERNAL_HOSTPORT`) |
| Python version not 3.12 on Render | build log shows other version | `PYTHON_VERSION` env (full version, e.g. `3.12.7`) |
| Llama key/model not available (waitlist, wrong id, region) | `llama_smoke` 401/403/404 | Stop and ask. Options: correct model id from `/compat/v1/models`; or same Llama model via another OpenAI-compatible host (needs Bhargavi's OK and a new key) |
| Neon compute asleep | first `db` check slow / false | 5 s timeout + `pool_pre_ping`; acceptable |
| Credits run out before Dec 15 | Render billing page | 2 services in P0 (~$14/mo), worker from P3 (~$21/mo total) fits $50 through Dec 15; check balance at P5 |
| Free plan picked by mistake | service sleeps after idle | Must be **Starter** in `render.yaml` (`plan: starter`) |
